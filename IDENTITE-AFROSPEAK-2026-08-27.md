Document de travail pour caler le studio sur la chaîne **réelle**, et non sur
l'idée qu'on s'en fait. Sources : le flux RSS public de la chaîne
(`youtube.com/feeds/videos.xml?channel_id=UCTjpcgRxsR7TiFJi8Nrkb7A`), les pages
`@AfroSpeak` (onglets Vidéos / Shorts / Playlists / Communauté), et la page d'une
vidéo avec sa transcription complète. **Aucun chiffre n'est extrapolé** : ce qui
n'a pas pu être relevé est marqué « non accessible ».

dessus.

## 4. Signature de packaging (ce que le studio doit reproduire)

**Titre** — `emoji + MOTS EN MAJUSCULES + question + parenthèse-promesse` :
`🚨 IRAN, VENEZUELA : Pourquoi Poutine et Xi Jinping ne bougent-ils pas ?`
`📢 L'ÉCOLE AFRICAINE EST UN MENSONGE : Voici la vérité.`
Emojis signature : 🚨 📢 🛑  📌  + drapeaux 🇲🇱🇫🇳🇪🇨.
Les titres anglais vus çà et là sont les **traductions automatiques** de YouTube,
pas des choix éditoriaux : l'original est français.

**Description** — 8 blocs dans un ordre très stable :
1. accroche = une **question adressée au spectateur**, souvent un fait visuel
   (« Regardez ces images d'écoles en ruines... Est-ce vraiment avec cela que... ») ;
2. contexte en 2-3 phrases avec « **Dans cette enquête exclusive d'AfroSpeak**, nous… » ;
3. liste à puces emoji de ce qu'on va découvrir (👉 🔍 ✅ 🧠 ⚠️ ️) ;
4. ligne de posture : « Nous ne sommes pas ici pour critiquer gratuitement, mais
   pour proposer… » / « nous refusons les récits officiels pour décrypter les faits bruts » ;
5. **chapitres** « DANS CETTE VIDÉO : 0:00 - … / 1:30 - … / 10:30 - Conclusion : … » ;
6. débat : « PARTICIPEZ AU DÉBAT : Pensez-vous que X sera une réussite ou un saut
   dans l'inconnu ? Répondez en commentaire ! 👇 » ;
7. soutien : « 🔔 ABONNEZ-VOUS… 👍 Likez… 🔁 Partagez… » ;
8. hashtags : **10 à 17**, toujours `#AfroSpeak` + pays + thème
   (`#AES #Mali #FrancCFA #EconomieAfrique #Souveraineté #Afrique2026 #EveilDesConsciences`) ;
9. et, sur plusieurs vidéos : « **SOURCES DE VISUELS : ORTM, TV5MONDE, FASO INFO,
   Facebook…** » / « Sources de visuels: RTI Info, Life TV, Facebook, Google… ».

**Ton** : première personne du pluriel (« nous révélons », « nous analysons »),
apostrophe directe (« vos diplômes », « notre continent »), phrases courtes,
**maxime de clôture** (« Le réveil a sonné. À nous d'écrire l'histoire. »).

**Communauté YouTube** (activée récemment) : posts de positionnement —
« Soutien total aux armées maliennes 🇲🇱 », « 🔴 SOUTIEN AU PEUPLE IRANIEN —
✊ Solidarité. Dignité. Liberté. » — 2 à 10 likes par post.

## 5. Facebook : rien à trouver, et ce n'est pas un hasard de recherche

- `facebook.com/afrospeak` → **HTTP 403**, mur de connexion (aucun contenu public servi).
- Recherche web : aucune page AfroSpeak indexée. Les homonymes sont **d'autres entités** :
  *Africa Speaks* (3,4 K abonnés, éducation), *AfroSpeak Language App* (appli de langues),
  *AfroSpeak* sur X (cabinet de communication à Johannesburg, 267 abonnés). **Aucun lien**
  avec la chaîne.
- Le dépôt documente déjà l'impasse technique (`FACEBOOK-ET-EQUIVALENTS.md`) : six voies
  testées le 21/08, toutes mortes (`gallery-dl` → `AuthRequired`, `mbasic` → 302,
  API Graph → `(#200) Provide valid app ID`, `fbcdn.net` → 403), et la permission
  « Page Public Content Access » exige l'App Review de Meta.

**Conclusion utile** : la chaîne **cite** Facebook comme pourvoyeur de visuels
(« SOURCES DE VISUELS : … Facebook ») mais le studio ne peut pas l'aspirer. Ce
qu'il faut donc reproduire d'eux n'est pas la source, c'est **la ligne de crédit
affichée** — `writeMeta()` (`lib/pipeline.js:2962`) assemble déjà « CRÉDITS MÉDIAS »
et « SOURCES ÉDITORIALES » ; il manque le bloc « SOURCES DE VISUELS » tel qu'eux
l'écrivent, et la densité de hashtags (5 demandés dans le prompt contre 10-17
réellement publiés).

## 6. Ce que ça change pour le test qui vient

1. **Sujet** : un sujet à l'intersection de leurs deux lignes (éco + souveraineté)
   battra un sujet d'entreprise pur. Trois qui collent au catalogue :
   « monnaie SAHEL adossée à l'or : génie ou isolement ? », « 90 Md$ de dette :
   qui est vraiment créancier en 2026 ? », « le miracle ivoirien et les loyers
   d'Abidjan ».
2. **Format** : sortir **le Short vertical d'abord** (9:16, preset `bankable`,
   karaoke — celui dont la plaque ne tremble plus), puis la version longue.
3. **Registre — le seul vrai arbitrage** : l'ADN du studio interdit les slogans
   (« Zéro misérabilisme, zéro complaisance, zéro slogan militant »), la chaîne
   réelle assume la ferveur (soutiens affichés, « valeur divine », « Wakanda »).
   Recommandation : **narré sobre, packaging fervent** — la conversion se joue
   dans le titre, la 1ʳᵉ phrase et la description, pas dans l'éditorial.
4. **Ce que le studio ne produira pas** : les sujets « armées / victimes /
   personnalités » en visuel généré sont refusés par `lib/aiassets.js` (garde-fou
   anti-désinformation + mention « ILLUSTRATION IA »). Pour un sujet AES/sécurité,
   prévoir des visuels d'infrastructures, institutions, cartes — pas de
   reconstitution humaine.
5. **Réglage sans toucher le code** : `data/config.json` est fusionné sur les
   `DEFAULTS` (`lib/config.js:111`, `deepMerge`). Le `channel.cta` actuel dit
   « comprendre l'Afrique qui bouge » ; leur formule réelle est plus engagée.
   Écrire dans `data/config.json` :

   ```json
   { "channel": {
       "tagline": "Nous ne faisons pas que donner des nouvelles, nous décryptons l'avenir.",
       "cta": "Abonne-toi à AfroSpeak — comprendre l'Afrique qui se construit." } }
   ```

À noter : **① est déjà le fichier en place** dans le studio — `assets/logo-mark.png`
(1024 × 1190) est le même médaillon, avec une ombre portée incluse dans le PNG.
Le choix de ① ne demande donc pas de câblage, seulement un nettoyage (ci‑dessous).

### 8.1 Ce que le moteur impose (lib/renderer.js)

```
logoW = LOGO_WIDTH || round(W * 0,11)      // ≈118 px en 1080 vertical, ≈211 px en 1920 paysage
marge = H * 0,028 · opacité fixe 0,85 · positions : top-center ou top-right
greffe: scale=w:-1:flags=lanczos, format=rgba, colorchannelmixer=aa=0,85, overlay:format=auto
```

Trois conséquences, dans l'ordre où elles pourrissent un rendu :

1. **aucun color‑key** : `colorchannelmixer=aa=` *multiplie* l'alpha, il ne détourne
   pas. Un logo posé sur fond noir peint un **rectangle noir** sur les rushs
   (invisible sur le `#0B0F14` des slides, très visible en plan de jour).
   → **exigence n°1 : un PNG à alpha réel.**
2. **`scale=w:-1` ne garde que la largeur** : toute marge morte dans le PNG est
   retirée de la marque visible. Un emblème recadré au contour rend ~30 % plus
   grand que le même fichier paddingué.
3. **deux étages de texte = illisible à 118 px** : `findLogo()` (l.144‑156) le dit
   déjà — c'est pour ça que la pastille, et non le bloc, sert de filigrane.

Et un point de palette : or/vert/noir convergent avec les couleurs du studio
(`#F5A623` / `#00A651` / `#0B0F14`), mais le **vert foncé de « SPEAK » s'éteint**
sur les images étalonnées sombres (`lut.js` écrase les ombres) → prévoir une
déclinaison **1 couleur** pour l'incrustation.

### 8.2 Mesure, et non opinion

`scripts/preparer-marque.js` compose le bug à sa taille réelle sur trois fonds
plats (nuit 0x14181C, demi 0x6E7783, jour 0xE8E4DA), puis **soustrait le même
fond sans le logo** : ce qui reste est exactement ce que l'œil voit.
`saillie` = 95ᵉ percentile de l'écart de luminance · `emprise` = % de la boîte où
l'écart dépasse 12 pts · `marge morte` = % sous 3 pts.

| fichier testé | fond | saillie | emprise visible | marge morte |
|---|---|---|---|---|
| `assets/logo-mark.png` (médaillon, **①**) | sombre | 160 | **41 %** | 47 % |
| | demi | 86 | **53 %** | 42 % |
| | clair | 171 | **54 %** | 41 % |
| `assets/logo.png` (bloc horizontal, **②**) | sombre | 112 | 24 % | **70 %** |
| | demi | 75 | 28 % | 66 % |
| | clair | 161 | 33 % | 61 % |

Lecture : à taille de bug identique, le médaillon garde **le double d'emprise
visible** et +11 pts de saillie sur fond demi ; le bloc horizontal perd les
deux tiers de sa boîte (marge morte 61‑70 %) et sa tagline ne passe plus.
Dans les deux cas, la marge morte élevée dit la même chose : **recadrer au
contour, marge fixe de 4 %** — le médaillon actuel pourrait rendre ~30 % plus
grand sans toucher au code.

Planches témoins : `assets/marque-2026-08/comparaison-fond-{moyen,sombre}.png`
(1:1, les deux candidats côte à côte à 118 px et 211 px).

### 8.3 Réglages par format

| format | quoi | réglage |
|---|---|---|
| **9:16 court** | ① | `logoPos: 'top-center'` (déjà le défaut du style Impact). Le rail d'actions de YouTube occupe le bord droit, le titre/n@ le bas : le haut centré est la seule bande libre. 118 px de large, y = 3,5 % H. |
| **16:9 long** | ① | `top-right` avec `LOGO_WIDTH=150`‑ish, ou `top-left` si les cartes de fin « s'assoient » dessus — position non prévue par le code à ce jour. |
| **1:1** | ① | `top-center`, 118 px. |
| **miniature** | ② | via `LOGO_COMPLET` (`public/logo.png` / `assets/logo.png`), coin, ~14 % de la largeur — jamais le filigrane. |
| **carte d'intro/outro, habillage** | ② | pleine largeur, tagline lisible. |
| **avatar chaîne** | ① | centré dans un **cercle de 66 %** de 800 × 800 : YouTube recadre en rond, la queue de bulle est coupée sinon. |
| **bannière** | ② | dans la zone sûre 1235 × 335 centrée (2048 × 1152) : le bloc horizontal, pas le médaillon. |
| **dernier plan d'un 16:9** | rien | la carte de fin porte déjà le nom et le @ → `logoOverlay: false` sur ce plan. |

⚠ **`logoSize`, `logoOpacity`, `logoFade` des presets sont déclarés mais jamais
lus** (aucune occurrence hors `lib/presets.js:185`, qui ne lit que `logoPos`) :
promettre un réglage par format exige de les câbler dans le renderer. Non fait —
ça changerait la taille du bug dès le prochain rendu, et le test en cours doit
rester sur les réglages mesurés.

### 8.4 Procédure quand les PNG sont redéposés

```bash
node scripts/preparer-marque.js assets/marque-2026-08/sources/Embleme.png \
    --fond noir --out assets/marque-2026-08          # détourage + recadrage + planches
# puis, et seulement après avoir regardé les planches :
cp assets/marque-2026-08/logo-mark.png assets/logo-mark.png      # → `assets/ancien-logo/` d'abord
```

Le script n'écrase **aucun** fichier du studio : il écrit dans `--out`, avertit
si le fond n'est pas transparent (« le bug PEINDRA UN RECTANGLE »), et ne touche
pas au moteur.
